AI Gateway vs. AI Runtime — Guardrail Scope

AI Gateway guardrails cover Basic detections (Check Language, Detect Gibberish) and third-party guardrails. PII detection and content moderation are not included — those belong to AI Runtime (API Intercept / Network Intercept). If the customer needs inline DLP or prompt injection scanning, plan to pair the gateway with AIRS API Intercept.

4 Token Volume Sizing Essential

This is the number entered as Billion tokens per month on the CSP deployment profile form (Guide Step 1.3). Under-provisioning stops traffic; over-provisioning wastes credits. Both directions count — prompts and responses.

Token Conversion Formula

1 token = 4 characters

Monthly tokens = (total characters sent + received per month) ÷ 4

Include system prompts, conversation history, retrieved context (RAG), and tool schemas — these often dominate counts in agentic workloads.

11 Workspace Access & Limits Essential

Feeds Guide Step 3.5. Budget and rate limits cannot be edited after creation by any organization member. Decide these values deliberately. The minimums are $1 (cost budget) and 100 tokens (token budget); setting a rate limit to 0 disables the provider for that workspace.

Budget & Rate Limits Are Immutable After Creation

Once you click Apply for a workspace's limits, no organization member can edit them. If limits need changing, you must remove the workspace provisioning and re-provision with new values. Decide the budget amount, type, reset cadence, and rate values before the configuration session — not during it.
