Data Privacy Note

Models are never uploaded to Palo Alto Networks. The SDK/CLI runs locally on the customer's infrastructure, scanning models in place. Only scan metadata, policy outcomes, and verdicts are sent to the AIRS cloud. No model files, training data, or weights leave the customer's environment.

BLOCKED vs. MALICIOUS — Critical Distinction

BLOCKED means a policy rule was violated (unapproved format, unverified org, license issue). The model may not be dangerous — it just didn't pass policy. Remediation: review the rule, fix the model, or request an exception.

MALICIOUS means the model contains confirmed threat indicators (embedded code execution, known malware signatures). This is a security incident. Do not use the model. Escalate immediately.

▶Consultant Notes

The safetensors migration recommendation: Many enterprises are unaware that safetensors is a drop-in replacement for pickle-based formats that eliminates deserialization risk entirely. For any customer with pickle-based models, the #1 remediation is: migrate to safetensors where available. Most popular HuggingFace models already have safetensors versions.

Remediation table for common blocked reasons:

  • Pickle deserialization detected: Find safetensors version of the model. Low effort.
  • Unverified HuggingFace org: Add org to allow list in security group. Low effort.
  • Invalid/missing license: Contact model author or find alternative. Medium effort.
  • Model architecture backdoor: Do NOT use this model. Report to source. No fix possible.
  • Runtime code execution in Keras: Convert to SavedModel or request vendor fix. Medium effort.

Break-glass is mandatory for production pipelines. Without one, a false positive or scan outage blocks all model deployments.

9 Environment & Network Essential

Model Security is outbound-only — the SDK on the customer's CI/CD runner calls out to AIRS cloud APIs. No inbound connectivity is needed. Feeds Guide Phase 2: Prerequisites.

Three Known Deployment Blockers — Address Before Kickoff
  1. TLS Decryption (HIGH): Enterprise SSL inspection re-signs traffic; the AIRS SDK and HuggingFace SDK reject self-signed certs. Fix: get the corporate CA cert bundle and set REQUESTS_CA_BUNDLE env var.
  2. Python Dependencies (HIGH): Artifactory/Nexus may block SDK dependencies due to flagged CVEs in TensorFlow (disputed, 5+ years old) or missing license declarations. Fix: request infosec exceptions or use a Docker container workaround.
  3. Proxy & Endpoint Access (MEDIUM): Enterprise proxies may block scan endpoints, the private PyPI registry, or HuggingFace. Fix: provide the full endpoint allowlist at kickoff.
