The following table describes the logical router’s Runtime Stats for BGP.
BGP Runtime Stats
Description

Enabled

Field is true if enabled, blank if not enabled.

Field is true if enabled, blank if not enabled.

Default local preference configured.
Graceful Restart
Field is true if enabled, blank if not enabled.

Number of seconds configured for Graceful Restart max peer restart time.
Stale Route Time (sec)
Number of seconds configured for Graceful Restart stale route time.
Always Compare MED
Field is true if enabled, blank if not enabled.
Deterministic MED Comparison
Field is true if enabled, blank if not enabled.

Up/Down

State
Established
