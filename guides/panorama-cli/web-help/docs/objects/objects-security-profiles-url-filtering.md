## Objects > Security Profiles > URL Filtering


You can use [URL filtering](https://docs.paloaltonetworks.com/advanced-url-filtering/administration/url-filtering-basics.html) profiles to not only control access to web content, but also to control how users interact with web content.



| What are you looking for? | See: |
| --- | --- |
| Control access to websites based on URL category. | [URL Filtering Categories](url-filtering-categories.html#ID0E6HRR) |
| Detect corporate credential submissions, and then decide the URL categories to which users can submit credentials. | [User Credential Detection](user-credential-detection.html#ID0EN2SR) [URL Filtering Categories](url-filtering-categories.html#ID0E6HRR) |
| Block search results if the end user is not using the strictest safe search settings. | [URL Filtering Settings](url-filtering-settings.html#ID0ERMSR) |
| Enable logging of HTTP headers. | [URL Filtering Settings](url-filtering-settings.html#ID0ERMSR) |
| Control access to websites using custom HTTP Headers. | [HTTP Header Insertion](http-header-insertion.html#ID0EWKTR) |
| Enable cloud and local inline categorization to analyze web pages in real-time for malicious content. | [Inline Categorization](inline-categorization.html#ID0ECCUR) |
