# Objects > Security Profiles

*Objects : Objects &gt; Security Profiles*

## Objects > Security Profiles


Security profiles provide threat protection in Security Policy. Each Security policy rule can include one or more Security Profiles. The following are available profile types:




| • | Antivirus profiles to protect against worms, viruses, and trojans and to block spyware downloads. See [Objects > Security Profiles > Antivirus](objects-security-profiles-antivirus.html#ID0ENGLR). |
| --- | --- |






| • | Anti-Spyware profiles to block attempts from spyware on compromised hosts trying to phone-home or beacon out to external command-and-control (C2) servers. See [Objects > Security Profiles > Anti-Spyware Profile](objects-security-profiles-anti-spyware-profile.html#ID0E5GMR). |
| --- | --- |






| • | Vulnerability protection profiles to stop attempts to exploit system flaws or gain unauthorized access to systems. See [Objects > Security Profiles > Vulnerability Protection](objects-security-profiles-vulnerability-protection.html#ID0E4QOR). |
| --- | --- |






| • | URL filtering profiles to restrict users access to specific websites and/or website categories, such as shopping or gambling. See [Objects > Security Profiles > URL Filtering](objects-security-profiles-url-filtering.html#ID0EQHQR). |
| --- | --- |






| • | File blocking profiles to block selected file types, and in the specified session flow direction (inbound/outbound/both). See [Objects > Security Profiles > File Blocking](objects-security-profiles-file-blocking.html#ID0EOMUR). |
| --- | --- |






| • | WildFire™ analysis profiles to specify for file analysis to be performed locally on the WildFire appliance or in the WildFire cloud. See [Objects > Security Profiles > WildFire Analysis](objects-security-profiles-wildfire-analysis.html#ID0EZFVR). |
| --- | --- |






| • | Data filtering profiles that help prevent sensitive information such as credit card or social security numbers from leaving a protected network. See [Objects > Security Profiles > Data Filtering](objects-security-profiles-data-filtering.html#ID0EEIWR). |
| --- | --- |






| • | DoS Protection profiles are used with DoS Protection policy rules to protect the firewall from high-volume single-session and multiple-session attacks. See [Objects > Security Profiles > DoS Protection](objects-security-profiles-dos-protection.html#ID0EQAXR). |
| --- | --- |






| • | [Mobile Network Protection](objects-security-profiles-mobile-network-protection.html#ID0EJAZR) profiles enable the firewall to inspect, validate and filter GTP traffic. |
| --- | --- |




In additional to individual profiles, you can combine profiles that are often applied together, and create Security Profile groups (**Objects** > **Security Profile Groups**).
