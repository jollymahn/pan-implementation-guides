# Panorama > Device Deployment

*Panorama Web Interface : Panorama &gt; Device Deployment*

## Panorama > Device Deployment


You can use Panorama to deploy software and content updates to multiple firewalls and Log Collectors and to manage firewall licenses.



| What are you looking for? | See: |
| --- | --- |
| Deploy software and content updates to firewalls and Log Collectors. | [Manage Software and Content Updates](manage-software-and-content-updates.html#ID0E4PA4) |
| See which software and content updates are installed or available for download and installation. | [Display Software and Content Update Information](display-software-and-content-update-information.html#ID0E6YB4) |
| Schedule automatic content updates for firewalls and Log Collectors | [Schedule Dynamic Content Updates](schedule-dynamic-content-updates.html#ID0EBLC4) |
| Revert the content versions of one or more firewalls from Panorama. | [Revert Content Versions from Panorama](panorama-dynamic-updates-revert-content.html#ID0EUBD4) |
| View, activate, deactivate, and refresh licenses. See the status of firewall licenses. | [Manage Firewall Licenses](manage-firewall-licenses.html#ID0EOYD4) |
| Looking for more? | [Manage Licenses and Updates.](https://docs.paloaltonetworks.com/panorama/11-1/panorama-admin/manage-licenses-and-updates.html) |
