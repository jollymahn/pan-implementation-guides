# Hardware Security Operations

*Device : Device &gt; Setup &gt; HSM : Hardware Security Operations*

Hardware Security Operations

To perform an operation on the [Hardware Security Module](https://docs.paloaltonetworks.com/pan-os/11-1/pan-os-admin/certificate-management/secure-keys-with-a-hardware-security-module) (HSM) or the firewall connected to the HSM, select **Device** > **Setup** > **HSM** and select one of the following Hardware Security Operations:



| Hardware Security Operations |
| --- |
| Setup Hardware Security Module (`nCipher nShield Connect and SafeNet Network`) |
| Set Up HSM Connectivity Account (`Thales CipherTrust Manager only`) |
| Restart HSM Connection (`Thales CipherTrust Manager only`) |
| Set Up HSM Crypto User Account (`Thales CipherTrust Manager only`) |
| Show Detailed Information |
| Synchronize with Remote Filesystem (`nCipher nShield Connect only`) |
| Reset Configuration (`nCipher nShield Connect and SafeNet Network`) |
| Select HSM Client Version (`SafeNet Network only`) |
| Clear HSM Configuration (`Thales CipherTrust Manager only`) |
