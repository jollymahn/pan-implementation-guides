These settings define the methods that the User-ID agent uses to perform user mapping.

| Enable the User-ID agent to probe client systems for user mapping information. | [Client Probing](user-id-agent-setup-client-probing.html#ID0E2J4Z) |
| Ensure that the firewall has the most current user mapping information as users roam and obtain new IP addresses. | [Cache](user-id-agent-setup-cache.html#ID0ENV4Z) |
