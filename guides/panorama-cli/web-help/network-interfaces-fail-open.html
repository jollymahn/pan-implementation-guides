Network > Interfaces > Fail Open
Certain firewall models have fail-open ports that can be configured to provide a pass-through connection in the event of a power or operating system failure. This feature is disabled by default and must be enabled by selecting Enable Fail Open.
The following firewalls support Fail Open:
Firewall Model
Fail-Open Ports
PA-450R
Ports 3 and 4
PA-450R-5G
Ports 3 and 4
PA-410R
Ports 1 and 2
PA-410R-5G
Ports 1 and 2
