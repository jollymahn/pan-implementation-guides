Panorama > Firewall Clusters
View the CN-Series firewall clusters summary and monitoring information in the Panorama web interface under Firewall Clusters.
(Only available on the CN-Series firewalls) From the Panorama > Admin roles > Web UI list, select Firewall Clusters, then click Enable to access firewall clusters. After you add firewall clusters to Panorama, use the web interface to view the details of the CN-Series firewall clusters.
Note:
You must install the Clustering plugin from Device > Plugins to view the cluster details under Firewall Clusters.
