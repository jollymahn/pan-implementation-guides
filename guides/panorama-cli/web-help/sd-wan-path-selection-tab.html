SD-WAN Path Selection Tab
•
Policies > SD-WAN > Path Selection
Select the Path Selection tab to define paths for applications or services traffic to swap to if the primary path quality exceeds the configured path quality thresholds in the Path Quality Profile.
Field
Description
Traffic Distribution Profile
From the drop-down select a traffic distribution profile, which determines how the firewall selects an alternate path for the application or service traffic when one of the path health metrics for the preferred path exceeds the threshold configured in the path quality profile for the rule.
