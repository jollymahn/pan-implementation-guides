About this section

The Prisma AIRS AI Gateway is the Palo Alto Networks native gateway for AI traffic. Every LLM prompt, Model Context Protocol interaction, and agent-to-agent exchange routes through it, gaining unified visibility, guardrails, budgets, rate limits, and model allowlists. The gateway is managed end to end in Strata Cloud Manager and runs either as SaaS or as a Hybrid data plane in your own Kubernetes cluster.
