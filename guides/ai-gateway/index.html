About this section

The Prisma AIRS AI Gateway is the Palo Alto Networks native gateway for AI traffic. Every LLM prompt, Model Context Protocol interaction, and agent-to-agent exchange routes through it, gaining unified visibility, guardrails, budgets, rate limits, and model allowlists. The gateway is managed end to end in Strata Cloud Manager and runs either as SaaS or as a Hybrid data plane in your own environment, on Kubernetes (EKS, AKS, GKE, or on-premises) or on a managed container platform (Amazon ECS or Azure Container Apps).

Two ways to install a Hybrid data plane

The Hybrid guides above are not alternative write-ups of one procedure. They document two install paths that use different charts, and mixing them leaves two data planes syncing against a single Organisation ID.

  • SCM wizard path — the Gateway Registration wizard generates a values.yaml for the airs-gw chart. Needs Kubernetes, works on any conformant cluster, and is documented in Phase 2 of the deployment guide.
  • Platform-page path — the portkey-ai/gateway chart on Kubernetes, or Terraform on ECS and Container Apps. Documented in EKS, AKS, and GKE and ECS and Container Apps.

If you are not sure which suits you, Which path are you on? compares them on connectivity, endpoints, and whether Palo Alto Networks has to be involved.
