VM-Series Deployment Models

The VM-Series guide covers three OCI deployment models. All use a VCN (Virtual Cloud Network) with per-subnet route tables and a Dynamic Routing Gateway (DRG) for hub-and-spoke connectivity. Deploy with the joint oracle-quickstart/oci-palo-alto-networks Terraform module, an Oracle Resource Manager (ORM) stack, or the PaloAltoNetworks/OracleCloud sample template.

OCI Architecture

Unlike AWS (Gateway Load Balancer) and Azure (Gateway Load Balancer), OCI has no dedicated firewall-insertion load balancer. The recommended pattern places VM-Series firewalls in a central hub VCN with spoke VCNs attached to a DRG. In the Active/Active model, an OCI Flexible Network Load Balancer with symmetric hashing ensures return traffic lands on the same firewall that saw the forward flow, so both firewalls stay active with no failover API calls. In the Active/Passive model, a pair of firewalls runs native PAN-OS HA and moves a floating secondary IP between peers through OCI API calls.

Cloud NGFW Not Available on OCI

Palo Alto Networks Cloud NGFW is offered as a managed service on AWS, Azure, and GCP only. On Oracle Cloud Infrastructure, the VM-Series firewall is the inline inspection option. There is no OCI Cloud NGFW card because the managed service does not exist for this cloud.
