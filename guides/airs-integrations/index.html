Prisma AIRS Integrations

Process-driven implementation guides for embedding Prisma AIRS AI Runtime Security into third-party platforms

AIRS API Intercept AIRS Network Intercept AIRS Cloud Deploy AIRS K8s

Prisma AIRS provides inline security for AI applications, scanning prompts, responses, and tool interactions in real time. It detects threats like prompt injection, sensitive data exposure, malicious URLs, and toxic content before they impact your AI workflows.

These guides cover the end-to-end process for integrating AIRS into each platform, from prerequisites and credential setup through configuration, verification, and production hardening. Each guide is self-contained: follow it start to finish and you'll have a working, validated integration.

Prerequisites for all integrations

Every integration requires an active Prisma AIRS license, a configured Security Profile in Strata Cloud Manager, and a generated API Key. The AIRS API Intercept guide walks through this setup in detail; complete it first if you haven't already.

Key Concepts

▶ AI Runtime Security (AIRS)

Inline security that scans AI traffic in real time. AIRS detects prompt injection, data leakage, malicious code, malicious URLs, and policy violations. It operates on three content types:

  • prompt — user input before it reaches the model
  • response — model output before it reaches the user
  • tool_event — tool/function call inputs and outputs (used by MCP-aware integrations)
▶ Strata Cloud Manager

The management interface for configuring Prisma AIRS. Used to:

  • Activate your AIRS license
  • Create deployment profiles (regional endpoint configuration)
  • Create security profiles (detection rules and actions — block, allow, alert)
  • Generate API keys for authenticating scan requests
▶ Regional API Endpoints
